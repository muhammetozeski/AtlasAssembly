# Maintaining project knowledge

Use [the index](İçindekiler.md) before researching. Keep product rules, the canonical engine and room API contracts at their existing sources of truth; update those documents when behavior changes. Put verified reusable implementation methods in subject articles and link them from the index.

Distinguish source inspection, official provider contracts, controlled clients/data and actual deployed observations. A proposed method is not an executed result. Record the prerequisites, responsible source/function and evidence needed to repeat a verified method. Exclude secrets, raw logs, routine action diaries and speculative commercial outcomes.

Use the timestamped Walkthrough for delivery state and handover lessons instead of repeating progress in these articles. Keep documentation and code English; the user conversation is Turkish.
